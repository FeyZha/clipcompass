# ClipCompass

从收藏的视频中找到相关讲解，查看章节报告，并跳转到原视频的对应时间。

## 功能

- 具体问题定位与宽泛主题学习报告。
- 章节、关键片段及原视频来源追踪。
- 无充分证据与需补充问题的独立状态。
- 本地版本支持浏览器侧栏、收藏整理和 Obsidian 单向导出。

## 在线演示

公开 Demo 使用 8 视频章节测试集的 14 个已保存测试结果，包含正常、无结果和澄清场景。不调用大模型，也不提供 API 配置。自由输入仅支持与已保存问题一致的内容。

## 快速开始

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory demo
```

打开 http://localhost:8080，选择测试问题并点击查找。

## 项目结构

- `demo/`：可独立部署的静态网页及预制数据。
- `library/`：检索、章节整理、收藏与本地服务实现。
- `extension/`：浏览器侧栏源码。
- `llm/`、`schemas/`、`tests/`：模型协议、数据约束和测试。

## 验证

```sh
node extension/test.mjs
python demo/check.py
```
