## 自动整理（当前版）

点击收藏 → 本地后台队列 → 获取中英文公开字幕 → 按内容划分、归纳章节 → 建立章节语义索引 → 自动进入检索。侧栏展示排队、字幕、章节、索引、完成或失败；失败可重试。旧版仅保存的链接在重新加载扩展并连接服务后自动提交。

提交后关闭侧栏不影响任务；服务重启恢复队列，复用已完成的字幕和章节步骤。离线收藏暂存浏览器，在侧栏下次连接时提交。同时整理最多 2 个视频，每个视频最多并行归纳 3 个章节，最多排队 100 个。本地建索引仍与搜索共用模型锁，串行执行；进度按实际完成章节计数，章节最终按原视频顺序排列。章节失败时取消尚未开始的归纳，等待在途请求结束并保存检查点后再显示失败，重试不重复已成功的步骤。字幕提交给现有 DeepSeek，产生 API 用量；不下载视频、不读取浏览器 cookies、不绕过平台限制。当前要求可用中英文字幕、非直播、时长不超过 3 小时且字幕不超过 20 万字符。

新增资产、进度、检查点位于 `runtime/chapter_pilot_v1/live/`，不改冻结的 8/50 视频数据或标准答案。新增视频按章节描述召回、原字幕核实；原库保留小窗口＋章节双路检索。新内容完成后以完整快照生效，不需要重启服务；尚未提供已提交任务的取消、删除或跨设备同步。

自动整理仅在 `--chapters` 入口启用。字幕工具复用本项目已准备的 `work/caption-tools/yt_dlp`；缺失时明确报错，不自行安装。来源限制或无字幕会显示失败而非假装可检索。开发自检：`python -B -m unittest library.tests.test_ingestion -v`。下文“仅保存链接”等为初版历史验收记录。

现有逻辑检查点：`82669d7`。扩展直接复用本机 `/api/library` 和 `/api/search`，没有改后端检索、提示词、章节或冻结标准。

## 安装与体验

1. 使用桌面 Chrome 116+，打开 `chrome://extensions`，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择 `D:\My_events\智能视频知识助手\extension`。
3. 将“ClipCompass | 视频知识库与学习助手”固定到工具栏。在任何网页点击扩展图标打开侧栏。
4. 本机 1485 服务已启动时可直接提问。侧栏“设置”可检查连接、调整本机端口；无需进入独立产品网页。

若本机服务未运行，由开发者启动：

```powershell
python -B mvp.py --collection mixed50 --chapters --no-open --port 1485
```

这是依赖本机服务的开发体验版，不是免安装后端的商店产品；没有发布扩展、自动安装进用户浏览器或提供移动端支持。

## 已实现

- 所有网页共用一个全局侧栏，包含找知识、整理状态和设置；不注入或读取非 YouTube 网页。
- 基础试验库 8 视频、96 内容单元，支持动态新增；2026-09-28 收尾检查实际 10 视频、179 内容单元。扩展从接口读取范围，不硬编码视频条数。
- 真实问题请求现有服务；显示章节报告、证据理由、整章/关键点、内部导航和缺失方向。澄清、技术失败与无证据分别提示。
- 最近报告、草稿、功能页和滚动位置保存于浏览器。关闭再打开可恢复完成的报告；进行中的网络请求可能中断，不承诺后台持续生成。
- 点击结果：当前是 YouTube 视频则复用该标签，同视频尝试定位播放器；否则仅复用本窗口内扩展创建的播放标签，没有则新建。不会覆盖非 YouTube 页面，也不会随意接管另一个既有视频标签。
- 当前 YouTube 视频可一键收藏并自动提交后台整理；重复收藏被阻止。离线链接在重新连接后提交。可移除尚未提交的链接，已提交任务暂不提供删除。
- 整理状态只显示未完成或失败的任务；报告支持章节内部导航。设置页提供本地连接、Obsidian 单向导出和清除问题/报告。

## 权限与边界

仅 `sidePanel`、`storage`、`scripting`，以及 YouTube 和 `127.0.0.1` 的地址权限；无全站读写、cookies、history 或 tabs 敏感信息权限。只在用户点击观看时对目标 YouTube 播放器执行定位。

地址权限不支持按端口细分，但实际请求固定 loopback，设置只接收 1024–65535 端口。连接由扩展自身发起，没有给服务添加宽泛跨域许可或开放网络监听。

问题和候选字幕仍由现有服务发送 DeepSeek；扩展自身不保存 API key。浏览器保存报告与新增链接，服务仍保留原有诊断日志。“清除问题与报告”不删除服务日志或收藏。

当前按单用户、单侧栏编辑设计，多窗口同时编辑同一收藏状态尚无冲突合并。打开的视频可能因网络、地区或账号限制不可播放；不会绕过这些限制。没有自动结束停播或连续播放，必要时用户在 YouTube 按播放。
