# ClipCompass 图标

使用内置 imagegen 生成，原图保存在 `icon-master.png`；等比例缩小导出 16、32、48、128 像素 PNG，分别用于工具栏与扩展管理页。透明圆角外沿，深色底与荧光绿 C 形指南针，不包含文字。

更新后在 `chrome://extensions/` 点击 ClipCompass 的重新加载按钮。

## 生成提示词

Use case: logo-brand. Create ONE finished square browser extension icon for ClipCompass, a saved-video knowledge library and learning assistant. No text. Not a mockup, no presentation board. Flat crisp vector-like geometric icon optimized to remain readable at 16px. A near-black charcoal (#20231d) rounded square tile fills 94% of the canvas, genuinely transparent outside its rounded corners. Center a bold acid-lime (#d9ff4c) almost circular C-shaped compass arc open toward the upper right; inside, one substantial lime triangular play/compass pointer pointing upper right, with deliberate negative space between pointer and arc. The C arc must be thick and simple, not multiple rings. Combines video playback with finding direction, not a YouTube logo. Balanced generous internal padding, strong silhouette, strictly two flat colors, no gradients, no shadows, no textures, no tiny compass ticks, no letters, no words, no watermark. Canvas 1024x1024 PNG with alpha transparency. This is a production icon asset, not a photo.
